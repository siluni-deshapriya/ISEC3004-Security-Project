# ISEC3004 Assignment 1 - Security Vulnerability Demonstration (Group 6)
 
## About
 
A set of small apps that demonstrate common security vulnerabilities, each with a working exploit and a mitigated version. Built for ISEC3004 at Curtin University to show how the flaws arise and how to defend against them.

## What You'll Learn
 
- How each vulnerability works and why the code is exploitable
- How an attacker exploits it in practice
- How to mitigate it, and why the fix works
